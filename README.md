# Alfan Praditiya Agustianto — Bento Portfolio

Modern interactive SPA using **Glassmorphism + Bento Grid**.

## Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Tailwind CSS CDN
- Font Awesome CDN
- AOS CDN
- No npm/yarn/pnpm, no framework, no build step

## Interactions
- Responsive Bento Grid
- Pointer-following glow
- Desktop card tilt
- Touch/click ripple
- Tap pulse feedback
- Magnetic buttons on desktop
- AOS scroll reveal
- Active-section micro glow
- Preloader and back-to-top
- Reduced-motion support

## Profile image
Edit `script.js`:
```js
const PROFILE_IMAGE_URL = "";
```
Use a direct image URL when ready.

## Deployment
Upload the folder to Vercel as a static site. No installation or build command is required.
